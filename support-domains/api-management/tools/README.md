# API Management Tools

Reusable APIM tools live here, with their own usage, source documentation, tests and maturity labels. They do not grant permissions or standing approval.

| Tool | Purpose | Status |
| --- | --- | --- |
| [VNet checker](vnet-check/README.md) | Copilot-invoked SKU discovery and twelve-section HTML/JSON assessment, including NSGs and service endpoints | Candidate; offline tested, not live validated |

Use Azure MCP and installed diagnostic skills first for interactive incidents. These tools add repeatable, versioned checks rather than replacing those diagnostic surfaces.
