# Managed endpoints and safe application checks

Harbor IT Services is a fictional managed IT company for small businesses. Managed-endpoint support covers enrolled business computers and approved application-access questions.

For an application that will not open, note the application name, the time with your local offset, and the exact non-sensitive error text. Save current work before closing and reopening that application. Check whether other approved applications open. Use only your organization's approved application portal.

Do not disable security software, remove management profiles, install unknown utilities, run scripts, or grant remote access. Harbor's assistant cannot inspect a device or apply an update. It can explain this guidance and prepare a case for your review.

If normal approved application access still fails, select Managed endpoints and describe the symptom and business impact. Never include credentials or private files.
