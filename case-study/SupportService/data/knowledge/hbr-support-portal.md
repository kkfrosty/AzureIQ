# Using the Harbor support portal

The Harbor support portal is a fictional learning application. Sign in through the approved enterprise identity flow. There is no demo password, browser API key, or shared bearer credential.

Support shows company-grounded answers with stable document citations and an optional voice session. My Cases lists only cases owned by the signed-in customer. Service Status shows clearly labeled synthetic scenarios, not live provider telemetry.

Choose a listed Harbor service before searching or asking a question. If the assistant has insufficient evidence or a dependency is unavailable, it must say so rather than invent an answer.

Preparing a case creates only an expiring proposal. Review all fields in the confirmation card and deliberately confirm before a case is created. A spoken yes, chat message, or assistant tool call is never that confirmation.
